# Portfolio Website

My personal portfolio website hosted with GitHub Pages.

## Live
- https://impiyushkumar.github.io/

## Tech Stack
- HTML
- CSS / SCSS
- JavaScript

## Run locally
Option 1:
- Download the repo ZIP and open `index.html` in your browser

Option 2 (VS Code):
- Open the folder in VS Code
- Use the “Live Server” extension and open `index.html`

## Deploy
Push changes to the default branch — GitHub Pages will update automatically.
